# Regex Tab Keeper

**Regex Tab Keeper** は、アクセス可能なすべての Chrome ウィンドウで、登録済みの URL 正規表現に一致するタブだけを残し、それ以外を一括で閉じる Manifest V3 Chrome 拡張機能です。誤ってすべてのタブを閉じないように、実行前に残すタブと閉じるタブを確認し、さらに確認ダイアログを通過した場合だけ削除します。

> URL ルールを1件も有効にしていない状態では、一括削除を実行できません。

|項目|内容|
|---|---|
|対象|すべての Chrome ウィンドウ内のタブ|
|残す条件|少なくとも1件の**有効な**URL正規表現に一致すること|
|設定保存|Chrome拡張機能のローカルストレージ|
|設定移行|JSONのエクスポート・インポートに対応|
|実行保護|事前プレビュー、確認ダイアログ、0件ルール時の実行禁止|
|通信・収集|外部サーバーへの送信や分析は行いません。ルールは Chrome のローカルストレージにのみ保存されます。|

![Regex Tab Keeper icon](icons/icon-128.png)

タブの重なり、正規表現のワイルドカード、残す操作を表すチェックマークを組み合わせたアイコンを、ツールバーと拡張機能管理画面に表示します。

## 導入

Chromeで `chrome://extensions` を開き、**デベロッパーモード**を有効にしてから、**パッケージ化されていない拡張機能を読み込む**を選択し、このリポジトリのディレクトリを指定してください。`manifest.json` は拡張機能ディレクトリのルートに置く必要があります。[1]

|手順|操作|
|---|---|
|1|本リポジトリをクローン、またはZIPとして展開します。|
|2|Chromeで `chrome://extensions` を開きます。|
|3|画面右上の「デベロッパーモード」を有効にします。|
|4|「パッケージ化されていない拡張機能を読み込む」を押し、展開済みディレクトリを選択します。|
|5|ツールバーの拡張機能メニューから **Regex Tab Keeper** を開きます。必要に応じてピン留めしてください。|

## 使い方

最初に、残したいタブの URL を表す正規表現を1件以上登録します。ルールは複数登録でき、**いずれか1件に一致したタブが残ります**。次にポップアップ下部の「対象タブを確認」で結果を確認し、「一致しないタブを閉じる」を押します。確認ダイアログで了承すると、すべての Chrome ウィンドウにある不一致タブを閉じます。

### 正規表現の例

|残したい範囲|入力するURL正規表現|補足|
|---|---|---|
|特定ドメインのすべてのページ|`^https://example\.com/`|`https://example.com/` 以下だけを残します。|
|`www` の有無を問わないドメイン|`^https://(www\.)?example\.com/`|`www.example.com` と `example.com` の両方に一致します。|
|複数のサブドメイン|`^https://(docs|app)\.example\.com/`|`docs` または `app` のタブを残します。|
|Google検索とGoogleドキュメント|`^https://(www\.google\.com/search|docs\.google\.com/)`|目的のパスまで含めて絞り込みます。|
|URL末尾がPDFのページ|`\.pdf(?:\?.*)?$`|クエリ文字列の有無を許容して `.pdf` のURLを残します。|

文字列の先頭を固定するには `^`、末尾を固定するには `$` を使います。`.` は「任意の1文字」を意味するため、ドメイン内のドットに一致させたい場合は `\.` とエスケープしてください。フラグ欄には、例えば大文字・小文字を区別しない `i` を入力できます。

> 例として `example.com` だけを入力すると、URLの途中に `example.com` を含むタブも一致します。対象を限定したい場合は、`^https://example\.com/` のように書いてください。

## 安全設計

一括削除は不可逆になり得る操作であるため、拡張機能は次の保護を実装しています。

|保護|動作|
|---|---|
|入力検証|保存・インポート時に JavaScript 正規表現としてコンパイルできるか検証します。|
|有効／停止|各ルールを個別に有効・停止できます。停止中のルールは照合に使いません。|
|空ルール防止|有効ルールが0件の場合は、削除ボタンを無効化し、バックグラウンド側でも削除を拒否します。|
|事前プレビュー|実行対象となる「残すタブ」と「閉じるタブ」をURL付きで表示します。|
|二重確認|実行ボタンの後に、閉じる件数と残す件数を表示した確認ダイアログを出します。|
|対象範囲|すべての Chrome ウィンドウのタブを対象にします。実行前にプレビューで対象件数を必ず確認してください。|
|設定移行検証|1MB超のファイル、別形式のJSON、不正な正規表現を含む設定は読み込みません。|

Chromeの標準機能により、閉じたタブは履歴から復元できる場合がありますが、実行前にプレビューを必ず確認してください。

## 設定の移行

「設定の移行」からルールと有効状態をJSON形式でエクスポートできます。別のChromeプロファイルへ移す場合は、移行先に本拡張機能を読み込んだ後、「インポート」でファイルを選択してください。インポートは既存設定を丸ごと置き換えるため、先にエクスポートしてバックアップしておくことを推奨します。

## 開発・検証

依存パッケージはありません。Node.js 20 以上で、JavaScriptの構文検証と、正規表現・タブ分類・設定移行・バックグラウンドの安全チェックの回帰テストを実行できます。

```bash
npm ci
npm run check
```

Chrome に読み込んで確認する場合は、上記の自動テスト後に `chrome://extensions` から「再読み込み」を押し、専用のテスト用ウィンドウでプレビューと確認ダイアログを確認してください。普段使っているタブを使った削除操作の検証は避けます。

|ファイル|役割|
|---|---|
|`manifest.json`|Manifest V3、ポップアップ、サービスワーカー、必要権限を定義します。|
|`icons/`|ツールバーと拡張機能管理画面で使う16/32/48/128pxのPNGアイコンです。|
|`core.js`|正規表現の検証、ルール正規化、URL照合、タブ分類、設定移行を実装します。|
|`background.js`|すべての Chrome ウィンドウのタブ一覧取得と、安全チェック後の一括削除を担当します。|
|`popup.html` / `popup.css` / `popup.js`|ルール編集、プレビュー、確認付き実行、設定移行の画面を提供します。|
|`test/core.test.js`|正規表現、ルール正規化、タブ分類、設定移行を検証します。|
|`test/background.test.js`|Chrome API をモックし、プレビューと削除前の安全チェックを検証します。|
|`.github/workflows/ci.yml`|pull request と `main` への push で `npm run check` を実行します。|

アーキテクチャと処理の詳細は [実装解説](docs/implementation-guide.md) を参照してください。
